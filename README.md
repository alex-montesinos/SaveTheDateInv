# Haley & Alex · Save the Date

A postcard that opens to show the save-the-date video.

## Files
- `index.html`: the page (postcard, animation, video player, end card)
- `save-the-date.mp4`: the video (made web-ready so it starts playing right away)
- `poster.jpg`: still image shown before the video plays
- `stamp.jpg`: photo on the postage stamp
- `og-image.jpg`: preview image when the link is texted or shared
- `save-the-date.ics`: "Add to calendar" file for Apple and Outlook

## Publish on GitHub Pages
1. Make a new **public** repo on GitHub (for example `save-the-date`).
2. Click **Add file → Upload files** and drag in everything in this folder.
3. Go to **Settings → Pages**. Under "Branch", choose `main` and `/ (root)`, then click Save.
4. After a minute or two the site is live at `https://YOUR-USERNAME.github.io/save-the-date/`.
5. In `index.html`, replace `YOUR-USERNAME/YOUR-REPO` (two places near the top) with that address so link previews show the photo.
